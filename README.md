# Wanderlust — World Destinations Gallery

A responsive animated image gallery featuring destinations around the world.

## Destinations
Hong Kong, Paris, Switzerland, Japan, Santorini, Dubai, Bali, London, Singapore, Venice, New York and Rome.

## Features
- Animated photo cards and hover zoom
- Region filters and destination search
- Full-screen image preview
- Previous / next navigation
- Keyboard controls and responsive mobile layout

## Publish with GitHub Pages
Upload `index.html` and `README.md` to the repository root. Then open Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Photos load from Unsplash and require an internet connection.
